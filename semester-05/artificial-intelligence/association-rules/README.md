# Ассоциативные правила

Apriori на Python, 10 синтетических корзин покупок. Frequent itemsets с support ≥ 0.3; правила с confidence ≥ 0.6. Lift = confidence / support правой части. Значение больше 1 указывает на положительную ассоциацию, не причинную связь.

Запуск: `python apriori.py`. [Результаты](results.md).
