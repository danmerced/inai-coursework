# Алгоритмы поиска и нейронные сети

`graph_search.py`: BFS, DFS, ограниченный по глубине DFS, iterative deepening и A*. BFS и IDS минимизируют число рёбер в невзвешенном графе; A* минимизирует сумму весов при допустимой эвристике. DFS не гарантирует оптимальный путь.

`neural_basics.py`: обучение простого MLP-классификатора на синтетических данных и confusion matrix, прямой проход свёрточного фильтра и рекуррентной ячейки. CNN выделяет локальные признаки, RNN обновляет состояние последовательности. [Фактические результаты](results.md).

Запуск: Python 3, numpy и scikit-learn. Конкретное условие практики BFS не получено; это примеры по темам лекций.
