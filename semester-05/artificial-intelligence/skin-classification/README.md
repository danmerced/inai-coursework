# Skin Disease Classification Using AI

[Презентация проекта](proposal.pptx) — первоначальное предложение.

Тема индивидуального проекта: исследование классификации дерматоскопических изображений. Архитектура MobileNetV2, три кода классов (bkl, mel, nv). Данные HAM10000 не включены: получить их самостоятельно на разрешённых условиях, проверить права использования. Истинные клинические изображения не загружать в публичный репозиторий.

`train.py` — обучение, независимые train/validation/test группы по lesion_id, confusion matrix и classification report. При наличии весов MobileNetV2 использовать параметр --weights imagenet или локальные веса. `dashboard.py` показывает только метрики исследовательского набора, не принимает фото пациентов.

Демонстрация без медицинских изображений: `python demo.py` — искусственные геометрические текстуры. [Результаты синтетического опыта](results.md) не отражают качество медицинской модели.

```sh
pip install -r requirements.txt
python train.py --metadata dataset/HAM10000_metadata.csv --images dataset --weights imagenet
streamlit run dashboard.py
```

Модель на HAM10000 пока не обучена в этой среде; медицинские метрики не заявляются. Проект исключительно учебный, не предназначен для диагностики, клинического скрининга или принятия лечебных решений.
