# Обучающий тренажёр сортировок

Windows Forms: окно визуализации, отдельные окна алгоритмов и сравнительного анализа, меню. Пузырёк, выбор, вставки — предварительная тройка по силлабусу, назначенную тройку требуется уточнить. Цветом выделяются сравниваемые и меняемые элементы; выводятся шаги, сравнения, записи и время вычисления без визуализации. Генерация и вычисление шагов работают через два BackgroundWorker.

Открыть SortingTrainer.csproj в Visual Studio 2022 с .NET Desktop Development и .NET 8. [Руководство](manual.md). Сборка и UI ещё не проверены на Windows.
