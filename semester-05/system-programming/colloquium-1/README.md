# Коллоквиум 1 Массивы C#

Консольное приложение: ввод, вывод, статистика одномерного массива, поиск, вставка, удаление, проверка упорядоченности, бинарный поиск с сужением диапазона. List хранит одномерную последовательность с возможностью изменения размера.

Запуск: `dotnet run` в каталоге проекта (.NET 8). Индивидуальные критерии варианта не подтверждены, пример следует адаптировать после их получения. Сборка C# в текущей среде не выполнена.
