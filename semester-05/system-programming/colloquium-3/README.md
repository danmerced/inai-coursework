# OrderDesk

Учебный вариант многооконного приложения для обработки заказов: главное окно, каталог, создание заказа. SQLite, хранение цены в целых копейках, вычисляемая сумма, проверка остатка и атомарное создание заказа. Изменение текущей цены товара не меняет цену сохранённого заказа.

Открыть OrderDesk.csproj в Visual Studio 2022 (.NET 8 Desktop Development), восстановить NuGet и запустить. База создаётся в LocalApplicationData/INAIOrderDesk. [Руководство](manual.md).

Выбрана тематика интернет-магазина как пример; назначенная тема коллоквиума не подтверждена. Сборку и UI нужно проверить на Windows.
