# Документация и руководство пользователя OrderDesk

Приложение для учёта заказов небольшого магазина. Модель данных: Products (название, цена в копейках, остаток), Orders (покупатель, ссылка на товар, количество, сохранённая цена, дата). Связь один ко многим. При записи заказа остаток уменьшается условным UPDATE; вставка и изменение остатка входят в одну транзакцию, поэтому при ошибке откатываются.

Открыть каталог, выбрать товар в окне Новый заказ, ввести демонстрационное имя покупателя и количество. Сумма пересчитывается по цене и количеству. Нажать Сохранить и убедиться, что заказ появился в таблице. Заказы сохраняются в локальном файле SQLite. При закрытии и повторном открытии список сохраняется. Для проверки отказа указать количество больше остатка: запись не должна появиться, остаток не меняется.

Среда: Windows, Visual Studio 2022, .NET 8, Microsoft.Data.Sqlite. Не использовать реальные персональные данные в демонстрации. Необходимы фактический запуск, скриншоты окон и перенос руководства в Word для сдачи.
