# Лабораторный практикум Access (№1–8)

| № | Основное действие | SQL-материалы / макет |
|---:|---|---|
| 1 | Таблица «Сотрудники», сортировка, фильтр, формы | [payroll/schema.sql](payroll/schema.sql), [queries.sql](payroll/queries.sql); формы «Формуляр» и «Ленточная» |
| 2 | Форма зарплаты, вычисляемое поле, диаграмма | payroll_summary: ставка минус денежные удержания; диаграмма по сотруднику |
| 3 | Запросы с условиями и параметрами | [payroll/queries.sql](payroll/queries.sql), форма по payroll_summary |
| 4 | Отчёты | Группировка по должности, средние и итоговые значения |
| 5 | Commerce, связанные таблицы | [commerce/schema.sql](commerce/schema.sql): поставщики, товары, приход |
| 6 | Многотабличные и модифицирующие запросы | [commerce/queries.sql](commerce/queries.sql) |
| 7 | Макросы, кнопки управления | OpenForm: поставщики, товары, приход; Close, сортировка, кнопочная форма |
| 8 | Подчинённые формы, многотабличные отчёты | Поставщики → приход по supplier_id, товары → приход по product_id; отчёты по поставщикам и датам |

Запуск моделей из database-1: python3 run_sql.py access-practice/payroll; python3 run_sql.py access-practice/commerce.

## Работа в Access

Для №1–4 создать базу «Заработная плата». Маску телефона, поле фото, формы, вычисляемые поля и отчёты настроить в конструкторе. Для №5–8 создать Commerce, связать таблицы с обеспечением целостности; построить формы, макросы и отчёты через конструкторы. В отчёте зафиксировать реальные результаты, включая работу кнопок и главной/подчинённой формы.

SQL-модели относятся к этим лабораторным, но не заменяют нативные файлы Access. Готовые .accdb и результаты GUI-проверки отсутствуют. Индивидуальная тема собственной БД не установлена.

Результаты: [заработная плата](payroll/results.md), [Commerce](commerce/results.md). Схемы: [payroll](payroll/relationships.md), [commerce](commerce/relationships.md).
