# SQL Server — лабораторная №1

1. В SSMS подключиться к отдельному учебному Database Engine.
2. Через Databases → New Database создать SecurityDB. Изучить расположение файлов данных MDF и журнала LDF, начальный размер, рост и группы файлов.
3. Выполнить create.sql, получить обе базы и свойства файлов в результатах SELECT.
4. Закрыть подключения к MySampleDB. В меню Tasks → Detach отсоединить БД; скопировать её MDF/LDF в архив.
5. Через Databases → Attach выбрать файлы и восстановить доступ. attach-example.sql содержит шаблон команд с путями, которые необходимо адаптировать.
6. Повторить SELECT и проверить, что MySampleDB доступна.

Скрипт подготовлен для SQL Server; пользовательские файлы MDF/LDF и результаты выполнения SSMS не представлены.
