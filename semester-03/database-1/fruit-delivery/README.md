# Доставка овощей и фруктов

Семь таблиц: клиенты, поставщики, сотрудники, товары, заказы, позиции заказа, оплаты. Скрипты реализуют связи, заполнение, четыре требуемых запроса и многотабличный отчёт. Запуск: python3 run_sql.py fruit-delivery (из database-1).
 
[ER-диаграмма](relationships.md)

## План объектов Access

- Табличная форма «Товары» на запросе с ценой 90–160.
- Форма «Заказы» с подчинённой «Сведения о заказе», связь по order_id.
- Отчёт по заказам с группировкой по клиенту.
- Макросы OpenTable, OpenForm, OpenReport (режим печати/предпросмотра), MessageBox, QuitAccess.
- Главная кнопочная форма: товары, заказы, отчёты, выход.

SQL выполнен в SQLite. Формы, макросы и отчёты Access должны проверяться в Microsoft Access; файл .accdb не создан.
