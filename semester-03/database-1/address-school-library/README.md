# Практические работы Access: адреса, школа и библиотека

Проверить запросы: python3 run_sql.py address-school-library (из database-1).

1. База адресов: таблица address, форма «Анкета», маски для телефона (в Access), сортировка по фамилии, фильтр по городу, отчёт адресов.
2. База «Школа»: students и grades (связь 1:1). Форма ученика с ведомостью и отчёт со средним и суммарным баллом.
3. Библиотека: readers, books и loans. Форма читателя с подчинённым списком выдачи (reader_id), связанный справочник книг.

Исполняемый вариант модели и запросов — SQLite. Макеты форм и отчётов указаны для реализации в Access; нативный файл и формы ещё не проверены.
