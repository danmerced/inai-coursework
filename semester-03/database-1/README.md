SQL-часть моделей Access можно выполнить с помощью Python 3 и встроенного SQLite: python3 run_sql.py fruit-delivery. Аналогично запустить остальные каталоги с schema.sql и queries.sql. Данные демонстрационные.

Нативные .accdb, формы, отчёты и макросы предстоит проверить в Access; SQL Server №1 требует SSMS и учебного экземпляра сервера. Точные условия SQL №1-2, №1-3, №2–6 и ЛР №7–10 пока не получены полностью.

Фактические результаты SQLite сохранены в results.md соответствующих каталогов.
