# Bootstrap 5 — типографика

Bootstrap — CSS-фреймворк с адаптивной сеткой, утилитами и компонентами интерфейса. Варианты подключения: CDN, локальные файлы и пакет npm. Здесь используется CDN Bootstrap 5.3.8.

Плюсы: сетка, адаптивность, единообразие компонентов, быстрая разработка. Минусы: дополнительный размер стилей, типовой внешний вид без настройки, необходимость учитывать классы фреймворка.

Открыть index.html с доступом в Интернет, переключить тему, проверить навигацию и типографику.
