# Проектирование БД, транзакции, JDBC, ORM

- JDBC: cd jdbc && mvn compile exec:java
- Hibernate: cd hibernate && mvn compile exec:java

Демонстрации используют H2 в памяти; данные удаляются после запуска. JDBC показывает параметризованные запросы, commit и rollback, Hibernate — сущности и связи one-to-many и many-to-many.

Проектирование: таблица authors (1:N) books, таблицы books и genres (M:N через book_genre). Ключи id, author_id и составной ключ связующей таблицы предотвращают дублирование.

ACID: атомарность — вся операция или откат; согласованность — ограничения БД; изоляция — независимость параллельных транзакций; долговечность — сохранение подтверждённых изменений в постоянном хранилище. H2 in-memory используется только для демонстрации, не для долговременного хранения.
