Запуск отдельных программ: Java 17+; например, java colloquium-1/ExceptionsDemo.java. SQL-файлы второго блока предназначены для пустой тестовой базы MySQL. Для JDBC и Hibernate требуется Maven и загрузка зависимостей. Восемь автономных примеров Java запускаются непосредственно с JDK 17+. JDBC исходник компилируется, но JDBC/Hibernate необходимо запустить с зависимостями; MySQL-скрипты нужно проверить на самом MySQL.

Практические примеры охватывают изученные темы. Индивидуальные варианты трёх СРСП не подтверждены.
