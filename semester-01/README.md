## Проверка

- 69 тестов для независимых заданий Python.
- 17 тестов Django, включая регистрацию, авторизацию, CRUD и изоляцию данных, REST API.
- Системная проверка Django: без ошибок; изменения моделей имеют миграции.
- Материалы по математике и экзаменационные билеты не включены согласно определённому объёму.

## Что не найдено в исходном виде

- Исторические выполненные работы и отправленные преподавателю файлы не выдаются за восстановленные.
- Для СРС 5, 6 и 8 точные варианты условий не найдены; реализованы самостоятельные задания по указанным в силлабусе темам.
- Старый To-Do (курсовая) упоминается студентом. Новый учебный To-Do здесь не является исходным проектом прежних лет; его необходимо отдельно сопоставить с оригинальным репозиторием.
- По ВЧК итог 3 обозначает оценку; отдельного задания в доступном материале нет.
