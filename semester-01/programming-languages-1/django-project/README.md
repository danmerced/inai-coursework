# StudyDesk — Django: блог и менеджер задач

Учебный проект на Django, объединяющий блог и менеджер задач.

- **СРС 7 — Блог с CRUD**: личные записи, список, просмотр, создание, редактирование, удаление.
- **СРС 9 — Django web-приложение**: To-Do с регистрацией, входом, задачами, фильтрацией и отметкой выполнения.
- Материал лекций 10–15: MVT, маршруты, шаблоны, ORM, формы, аутентификация, REST API.

Оба приложения используют единую авторизацию, SQLite и одну конфигурацию Django, но имеют отдельные модели, маршруты, представления, сериализаторы. Данные изолированы по пользователям.

## Запуск локально

Необходим Python 3.10+.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и зарегистрируйте учебный аккаунт. База создаётся локально, секреты и реальные пользовательские данные не хранятся в репозитории.

| Маршрут | Назначение |
|---|---|
| /register/ | Регистрация |
| /login/ | Вход |
| /tasks/ | To-Do |
| /blog/ | Блог |
| /api/tasks/ | REST API задач |
| /api/posts/ | REST API блога |

API использует сессионную аутентификацию Django; для изменяющих запросов через браузер требуется действительный CSRF-токен. После входа можно пользоваться интерфейсом DRF. Для списков доступны GET/POST; для конкретных объектов — GET/PUT/PATCH/DELETE.

## Структура

```text
config/     настройки проекта, общие маршруты и регистрация
blog/       модель Post, CRUD, API, миграции
tasks/      модель Task, CRUD, фильтр, API, миграции
templates/ HTML-шаблоны
static/    CSS
```

## Проверка

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
```

Приложение предназначено для локального учебного запуска, не для публичного production-развёртывания; для последнего требуются собственный секрет, выключенный DEBUG и отдельная конфигурация безопасности.
