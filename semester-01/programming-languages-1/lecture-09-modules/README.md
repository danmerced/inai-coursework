# Лекция 9 — Модули и библиотеки

Два упражнения из [лекции 9](https://lms.inai.kg/Lesson/LessonViewNew/1123): создание модуля калькулятора и HTTP-запрос с Requests. По умолчанию запускается локальный учебный HTTP API, поэтому демонстрация не требует доступности стороннего сервиса. Можно передать собственный адрес через `--url`.

```bash
python -m pip install -r requirements.txt
python main.py
python -m unittest -v
```
