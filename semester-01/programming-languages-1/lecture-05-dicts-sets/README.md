# Лекция 5: словари и множества

[Источник](https://lms.inai.kg/Lesson/LessonViewNew/1119), слайды 48–57. Все десять задач: уникальные посетители, общие друзья, различия ассортимента (симметрическая разность), удаление дубликатов, подмножество, цены, частотный словарь, телефонная книга, средние оценки, данные сотрудников. Используются вымышленные примеры.

`python3 main.py` — демонстрации и ввод; `python3 -m unittest -v` — тесты.
