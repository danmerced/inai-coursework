# СРС 3 — Работа с файлами

Упражнения по теме лекции 6. Девять функций реализуют поиск строк, нумерацию строк, бинарное копирование изображения, журнал расходов, сумму продаж из CSV, резервное копирование TXT, общий отчёт, изменение яркости изображения и JSON-конфигурацию. Для денежных величин используется Decimal.

```bash
python -m pip install -r requirements.txt
python main.py add 120.50 транспорт
python main.py list
```
