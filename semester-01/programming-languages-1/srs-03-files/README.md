# СРС 3 — Работа с файлами

Восстановление по условиям [лекции 6](https://lms.inai.kg/Lesson/LessonViewNew/1120). Девять функций реализуют поиск строк, нумерацию строк, бинарное копирование изображения, журнал расходов, сумму продаж из CSV, резервное копирование TXT, общий отчёт, изменение яркости изображения и JSON-конфигурацию. Для денежных величин используется Decimal.

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python main.py add 120.50 транспорт
python main.py list
```

Тесты создают собственные файлы во временном каталоге, включая изображение.
