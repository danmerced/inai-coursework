# СРС №1 — средняя арифметическая температура каждой области

**Дисциплина:** Языки программирования 1, 1-й семестр.

**Источник:** [силлабус eBilim](https://lms.inai.kg/Lesson/LessonViewNew/1196), коллоквиум 1, СРС №1.

**Условие:** определить среднюю арифметическую температуру каждой области.

Программа принимает измерения температуры для семи областей Кыргызстана, введённые пользователем.

## Запуск

Требуется только Python 3, сторонние библиотеки не нужны.

```bash
python3 main.py
```

Введите по одному или несколько измерений (°C) через пробел для каждой области. Программа рассчитывает среднее по формуле sum / n, показывает названия областей и средние значения с двумя десятичными знаками. Пустые строки и нечисловой ввод отклоняются.

## Проверка

```bash
python3 -m unittest -v
```

В тестах проверяются положительные, отрицательные, дробные значения и один замер. Пример входа ниже — **вымышленные данные для проверки**, не метеорологические наблюдения.

| Область | Замеры | Среднее |
|---|---|---:|
| Баткенская | 10 12 14 | 12.00 |
| Джалал-Абадская | 8 10 12 | 10.00 |
| Иссык-Кульская | 3 5 7 | 5.00 |
| Нарынская | -12 -6 -3 | -7.00 |
| Ошская | 7 9 11 | 9.00 |
| Таласская | 2 4 6 | 4.00 |
| Чуйская | 5 7 9 | 7.00 |

## Пояснение

Для каждой области считывается строка измерений. Метод split делит её на отдельные значения, float переводит каждое значение в число, а словарь сохраняет среднее по названию области. Среднее — сумма замеров, делённая на их количество. Цикл for повторяет расчет для всех областей.
