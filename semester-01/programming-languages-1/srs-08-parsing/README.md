# СРС 8 — Парсинг

Самостоятельная практика по теме [силлабуса](https://lms.inai.kg/Lesson/LessonViewNew/1196). Учебный HTML-каталог: разбор названий и цен стандартной библиотекой, валидация цены и экспорт CSV. Фикстура синтетическая. Опция `--url` подходит для доступной страницы с той же структурой; перед её использованием проверьте разрешение на получение данных.

```bash
python -m pip install -r requirements.txt
python main.py
python -m unittest -v
```
