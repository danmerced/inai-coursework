# СРС №2 — списки и кортежи

**Дисциплина:** Языки программирования 1, 1-й семестр.  
**Источники:** [силлабус](https://lms.inai.kg/Lesson/LessonViewNew/1196), [лекция 4](https://lms.inai.kg/Lesson/LessonViewNew/1118), слайды 27–31.

Пять упражнений со списками из лекции 4 и демонстрация операций с кортежами. Используются демонстрационные данные.

| Задача из лекции | Реализация |
|---|---|
| Обновление ассортимента | Удаление через remove, добавление через append |
| Обновление CRM | sort и insert в нужную позицию |
| Анализ покупок | count заданного товара |
| Задачи на день | pop последней задачи, вывод оставшихся |
| Объединение каталогов | extend дополнительного списка |

Дополнительно для темы кортежей: индексация, срезы, длина, конкатенация, повторение, проверка вхождения, count, index и преобразование в список. В отличие от list, tuple неизменяемый; конкатенация создаёт новый кортеж.

## Запуск

```bash
python3 main.py
```

## Проверка

```bash
python3 -m unittest -v
```

Восемь тестов проверяют пять задач, пустые коллекции и операции с кортежем.
