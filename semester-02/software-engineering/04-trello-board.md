# Trello

## Система управления библиотекой

[Доска проекта в Trello](https://trello.com/b/IfseBFhz/saifullin-momunbekova) — рабочее пространство AIN-2.

На доске от 18 марта 2025 года размещены шесть пользовательских историй в Backlog. Также есть колонки «В процессе», «На тестировании» и «Готово». Доступ к доске ограничен участниками.

## План доски для системы расписания

Списки: Backlog, Sprint 1, Sprint 2, In progress, Review, Done.

[Карточки для переноса](trello-cards.csv): идентификатор, название, описание, список, роль, оценка.

## Правила

- Карточка имеет ID пользовательской истории и критерий завершения.
- Задача перемещается в In progress после начала, затем в Review.
- Done означает соблюдение критериев приёмки и проверку.
- Конкретного исполнителя назначает команда при создании доски.

Это отдельный план для проекта системы расписания; он не относится к доске проекта библиотеки.
