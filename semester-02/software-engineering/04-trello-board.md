# Trello — система управления библиотекой

[Доска проекта](https://trello.com/b/IfseBFhz/saifullin-momunbekova) · рабочее пространство AIN-2.

На оригинальной доске 18 марта 2025 года были созданы шесть карточек: БД, каталог, аккаунты и выдача, администрирование, резервное копирование, документация.

## Организация работы

| Колонка | Назначение |
|---|---|
| Backlog | Пользовательские истории и задачи, ожидающие реализации |
| В процессе | Начатые задачи |
| На тестировании | Задачи, ожидающие проверки |
| Готово | Задачи, прошедшие приёмку |

## Планирование спринтов

[Product Backlog](05-product-backlog.md) · [Sprint Backlog](06-sprint-backlog.md) · [Карточки задач CSV](trello-cards.csv).

Шесть исходных историй декомпозированы в 12 задач для двух спринтов. ID US01–US12 связывают задачи с требованиями и приёмочными сценариями.

На исходной доске все шесть карточек находятся в Backlog. Исполнители на карточках не указаны; распределение по конкретным участникам согласуется в команде. CSV отражает план спринтов, а не экспорт фактических назначений. Доступ к доске ограничен участниками.
