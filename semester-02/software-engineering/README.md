Документация проекта опирается на шесть исходных пользовательских историй [доски Trello](https://trello.com/b/IfseBFhz/saifullin-momunbekova). Требования F01–F12, истории US01–US12 и приёмочные сценарии связаны между собой. UML доступна в SVG и текстовом формате. Презентации оформлены в Markdown (Marp).

Документы описывают проект и план его реализации. Приёмочные сценарии определяют ожидаемые результаты, а не утверждают прохождение тестов.
