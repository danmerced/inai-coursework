# Sprint Backlog

## Sprint 1 — каталог и выдача (26 SP)

Цель: организовать полный основной цикл работы библиотеки.

| История | SP | Задачи | Роль |
|---|---:|---|---|
| US01 | 5 | Схема Account/Book/Loan; связи, ограничения и миграции | Backend |
| US02 | 5 | Форма книги; валидация ISBN, года и количества; сохранение и редактирование | Frontend, Backend |
| US03 | 3 | Фильтры каталога, сортировка, состояние пустого результата | Frontend, Backend |
| US04 | 5 | Регистрация и вход; хеширование; восстановление пароля; проверка роли | Backend, Frontend |
| US05 | 5 | Сервис выдачи/возврата; транзакция; запрет повторного возврата | Backend, QA |
| US06 | 3 | История читателя; статусы; фильтрация по аккаунту | Frontend, QA |

Демонстрация: зарегистрировать читателя, добавить книгу, найти её, выдать, проверить остаток и историю, оформить возврат.

## Sprint 2 — управление и надёжность (21 SP)

Цель: добавить административные функции и обеспечить сохранность данных.

| История | SP | Задачи | Роль |
|---|---:|---|---|
| US07 | 3 | Список пользователей; активность; блокировка; деактивация | Backend, Frontend |
| US08 | 3 | Запрос просрочек; уведомления; журнал отправки | Backend |
| US09 | 3 | Отчёты по популярности, активности и фонду; фильтры | Backend, Frontend |
| US10 | 5 | Ручное создание копии; расписание; контроль целостности | Backend |
| US11 | 5 | Проверка и восстановление копии; откат при ошибке | Backend, QA |
| US12 | 2 | Руководства читателя, библиотекаря и администратора; API | Documentation |

Демонстрация: заблокировать тестовый аккаунт, показать просрочки и статистику, создать копию, восстановить данные на тестовой БД.

Оба спринта планируются на две недели. Критерий завершения истории — выполнены связанные сценарии приёмки и проверены права доступа. Конкретные исполнители назначаются после согласования состава команды.
