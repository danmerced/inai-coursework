# Приёмочные сценарии

Сценарии для проверки реализации системы. Предусловия: отдельная тестовая БД, тестовые аккаунты читателя, библиотекаря и администратора, книги с известным количеством экземпляров.

| ID | Требование | Действия | Ожидаемый результат |
|---|---|---|---|
| AT01 | F01 | Создать книги и выдачи, перезапустить систему | Данные и связи сохранены |
| AT02 | F02 | Добавить книгу с валидным ISBN и годом; изменить название | Книга видна в каталоге с новым названием |
| AT03 | F02 | Добавить дубликат ISBN или неверный год | Сохранение отклонено |
| AT04 | F03 | Искать по автору, сортировать по году | Список соответствует фильтру и сортировке |
| AT05 | F04 | Зарегистрироваться, войти и выйти | Аккаунт создан, сессия завершается |
| AT06 | F04 | Повторить email, ввести неверный пароль | Ошибка, вход не выполнен |
| AT07 | F04 | Запросить восстановление, применить токен и повторить его | Пароль изменён один раз, повторное использование отклонено |
| AT08 | F05 | Выдать книгу с остатком 1, затем вернуть её | Остаток 0 после выдачи, 1 после возврата |
| AT09 | F05 | Выдать недоступную книгу, затем повторно вернуть закрытую выдачу | Обе операции отклонены, остаток не изменён |
| AT10 | F05 | Два сотрудника одновременно выдают последний экземпляр | Успешна максимум одна операция |
| AT11 | F06 | Войти читателем, открыть историю, запросить чужую выдачу | Доступна только собственная история |
| AT12 | F07 | Заблокировать аккаунт, попытаться войти | Вход запрещён, история выдач сохранена |
| AT13 | F08 | Создать открытую просроченную и закрытую выдачи; запустить уведомление | В списке только открытая просрочка; результат уведомления зафиксирован |
| AT14 | F09 | Выбрать жанр и период отчёта | Итоги соответствуют данным выбранного периода и жанра |
| AT15 | F10 | Создать ручную копию и запустить задание по расписанию | Обе копии созданы и способны пройти проверку |
| AT16 | F11 | Восстановить валидную тестовую копию; попробовать повреждённую | Валидные данные восстановлены, повреждённая копия отклонена |
| AT17 | F12 | Пройти сценарий выдачи по руководству; сверить описание API | Шаги и параметры соответствуют интерфейсу |
| AT18 | F02, F05, F07, F10 | Читателем вызвать операции изменения каталога, выдачи, блокировки и копирования | Сервис отклоняет неразрешённые действия |

Порядок: подготовить данные, выполнить сценарий, сравнить фактический результат с ожидаемым, записать результат и выявленные дефекты. Сценарии не являются фактическим протоколом выполнения.
