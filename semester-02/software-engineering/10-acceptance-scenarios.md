# Приёмочные сценарии

Проверки для будущей реализации. Фактические результаты ещё не получены.

| ID | Требования | Шаги | Ожидаемый результат |
|---|---|---|---|
| AT01 | F01–F02 | Ввести корректные данные студента | Открыт экран его группы |
| AT02 | F01 | Ввести неверный пароль | Вход отклонён, понятное сообщение |
| AT03 | F03–F04 | Выбрать дату с двумя занятиями | Показаны два занятия в порядке времени |
| AT04 | F04 | Выбрать день без занятий | «Занятий нет» |
| AT05 | F05 | Войти редактором и добавить корректную запись | Запись появилась в расписании |
| AT06 | F06 | Указать конец раньше начала | Запись не сохранена, ошибка |
| AT07 | F06 | Добавить занятие одной группы с пересекающимся временем | Сохранение отклонено |
| AT08 | F06 | Добавить занятие другой группы в занятой аудитории | Сохранение отклонено |
| AT09 | F05 | Изменить аудиторию и сохранить | Изменение видно при повторной загрузке |
| AT10 | F07 | Попытаться удалить запись и отменить | Запись остаётся |
| AT11 | F07 | Подтвердить удаление | Запись исчезает |
| AT12 | F08 | Закрыть и повторно запустить приложение | Сохранённые записи загружены |
| AT13 | F09 | Студент вызывает операцию редактирования | Операция отклонена сервисом |
| AT14 | F09 | Выйти и попытаться открыть расписание | Требуется вход |

Порядок: подготовить чистую локальную БД с учебными группами, выполнить сценарии, сравнить результат, записать статус и дефекты. Не использовать реальные пароли или персональные данные.
