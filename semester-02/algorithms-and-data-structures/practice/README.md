# Практические и лабораторные работы

## Практические (сортировки)

Все реализации и измерения находятся в [коллоквиуме 2](../colloquium-2/README.md).

1. Простые сортировки: bubble, selection, insertion, binary_insertion.
2. Улучшенные: heap, shell, quick.
3. Merge.
4. Radix LSD и MSD.

В results.csv приведены время, число сравнений, обменов и записей для размеров 100, 1000 и 10000, а также больших массивов.

## Лабораторные

| № | Работа | Файл |
|---|---|---|
| 1 | Поиск всех индексов ключа, линейный и бинарный | [search.c](search.c) |
| 2 | Поиск подстроки: прямой, KMP, Бойер–Мур (правило плохого символа) | [substring.c](substring.c) |
| 3 | Биномиальная очередь: вставка, слияние, извлечение максимума | [binomial_queue.c](binomial_queue.c) |
| 4 | Бинарное дерево: вставка, поиск, удаление, обход | [bst.c](bst.c) |

Каждая программа компилируется отдельно, например:

```bash
gcc -std=c11 search.c -o search
./search
```

Показаны варианты упражнений; номер, назначенный на индивидуальную лабораторную, нужно сверить.
