# Коллоквиум 3 — структуры данных

## Сортировки

[Алгоритмы и результаты](../colloquium-2/README.md). Вариант определяется формулой n mod 16 + 1, выбирается скриптом benchmark.py.

## Связные списки

[linked_text.py](linked_text.py): четыре вида списков, узлы linkable/linkableTwo, ListWithCursor, Text, все 12 правил обработки и три выравнивания. Нулевой остаток трактуется как последний вариант (это соглашение необходимо подтвердить у преподавателя). Переработанный текст снова хранится в выбранном связном списке; при преобразованиях используется временный список слов.

```bash
python linked_text.py sample.txt 7 --width 40
```

## Дерево поиска

[bst.py](bst.py): ключи, операции поиска/удаления и min/max для всех 12 вариантов. Вариант n mod 12 + 1.

```bash
python bst.py 7
```

## Хеш-таблица

[hash_table.py](hash_table.py): цепочки обычные и упорядоченные, линейное и квадратичное пробирование, двойное хеширование, удаление с маркером. Поддержаны все 10 комбинаций способов коллизий, а две полиномиальные хеш-функции приведены как самостоятельные примеры (формулы в исходном задании не читаются). Для открытой адресации таблица простого размера 53, демонстрация на 10 ключах.

```bash
python hash_table.py 7
```

## Дейкстра

[dijkstra.py](dijkstra.py): матрица смежности, min-heap, расстояния и пути ко всем вершинам. Все десять графов и пары вершин перенесены из схем вариантов. Пара (N₁,N₂) трактуется как начальная и выделенная конечная вершины. Вариант n mod 10 + 1.

```bash
python dijkstra.py 7
```

## Дополнительная задача

[service_simulation.py](service_simulation.py) — модель автосервиса с двумя очередями, приоритетной бинарной кучей и стоянкой вместимостью 10 с FIFO. Случайные интервалы обслуживания, статистика времени. Это демонстрация комбинации «куча + очередь»; другой назначенный вариант структуры нужно реализовать после определения номера.

```bash
python service_simulation.py
```
