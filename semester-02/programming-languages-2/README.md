# Языки программирования 2 — Java

Самостоятельная практика по темам трёх коллоквиумов.

| Коллоквиум | Темы |
|---|---|
| [1](colloquium-1/) | Main, типы, ввод, условия, циклы |
| [2](colloquium-2/) | Массивы, матрицы, методы, строки |
| [3](colloquium-3/) | Наследование, equals/hashCode, абстрактные классы, generics и коллекции |

Каждый Exercise запускается отдельно. Для примера:

```bash
cd colloquium-1
javac Exercise01.java
java Exercise01
```

Для индивидуальных СРСП необходимо уточнить назначенные варианты.
