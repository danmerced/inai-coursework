# Объектно-ориентированное программирование

Самостоятельный пример на Java: модель библиотеки. Классы Publication, Book и Magazine демонстрируют абстракцию, наследование, полиморфизм и инкапсуляцию. Интерфейс Catalog отделяет операции поиска и добавления от реализации Library. Выдача и возврат книги меняют её состояние; повторная выдача отклоняется.

Запуск: `java LibraryDemo.java` (JDK 17+). [Вывод программы](results.md).
