# Study Notes — Android

Самостоятельный учебный пример мобильного приложения на Java: добавление, просмотр, удаление текстовых заметок и локальное хранение в SharedPreferences. Сетевые разрешения не требуются. Черновик восстанавливается при повороте экрана.

Открыть каталог в Android Studio. Для заданной конфигурации нужны JDK 17, Android SDK 34 и Gradle 8.7. Синхронизировать Gradle, запустить app на эмуляторе или устройстве с API 23+. Gradle Wrapper не включён; можно использовать установленный Gradle 8.7.

Проверка на устройстве: добавить две заметки, перезапустить приложение, открыть и удалить одну заметку, повернуть экран с черновиком. Сборка и запуск на Android ещё не выполнены.

Точные технологии и задания дисциплины пока не подтверждены.
