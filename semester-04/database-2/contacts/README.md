# Контакты клиентов — уроки 1–7

Шесть таблиц: тип клиента, сфера деятельности, вид контакта, район, клиент, контакт. Внешние ключи идут от клиента к трём справочникам и от контакта к клиенту и виду контакта.

- `sql-server.sql` — создание чистой базы INAI_Contacts, заполнение и запросы 4, 6, 7.
- `02-ddl.sql`, `03-constraints.sql`, `05-dml.sql` — изменение структуры, ограничения, обновление и удаление.
- `schema.sql`, `queries.sql` — переносимый вариант для SQLite.
- [Результаты SELECT](results.md).

Данные синтетические: 6 записей в каждом справочнике, 12 клиентов и 72 контакта. Сначала справочники, затем клиент, затем контакт; удаление в обратном порядке. TRUNCATE удаляет все строки, DELETE допускает WHERE. Не выполнять скрипты на рабочей базе. SQL Server-специфичные команды требуют проверки в SSMS.
