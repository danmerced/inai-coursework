# Flower Shop — уроки 9 и 11

Модель магазина с товарами, поставщиками, покупателями, сотрудниками, поставками, продажами и платежами. Связь поставки с клиентом введена для выборок по клиентам. Даты интервалов: от включительно, до не включительно.

1. `01-create.sql` — новая демонстрационная база.
2. `09-procedures.sql` — 8 процедур поставок и 16 процедур продаж.
3. `09-call-procedures.sql` — примеры выполнения всех процедур.
4. `11-transactions.sql` — условная транзакция суммы, проверка фамилии и задолженности.

[Результаты выполнения тел процедур в SQLite](results.md). Обёртки T-SQL и транзакции требуют проверки в SQL Server.
