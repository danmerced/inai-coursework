Сначала выполнить 01_mssql.sql и 01_seed.sql в SSMS на пустом учебном экземпляре, затем работы 2–8 по порядку. Для импорта путь к CSV задаётся на сервере. Для PostgreSQL использовать psql и 02_postgres.sql после создания таблиц.

| Тип | SQL Server | PostgreSQL | MySQL | Oracle |
|---|---|---|---|---|
| Счётчик | IDENTITY(1,1) | GENERATED BY DEFAULT AS IDENTITY | AUTO_INCREMENT | GENERATED BY DEFAULT AS IDENTITY |
| Строка | NVARCHAR | VARCHAR | VARCHAR | VARCHAR2 |
| Дата | DATE | DATE | DATE | DATE |
| Логический | BIT | BOOLEAN | BOOLEAN (TINYINT) | NUMBER(1) (совместимый вариант) |
| Большой текст | NVARCHAR(MAX) | TEXT | LONGTEXT | CLOB |

Суммирование продаж по строкам заказа исключает двойной подсчёт суммы заказа. Роли в ЛР8 проверяются через пользователей WITHOUT LOGIN, для серверного входа нужны локальные логины.

[Результаты переносимых запросов и плана SQLite](results.md). Необходимы отдельные запуски в соответствующих СУБД, реальные скриншоты, измерения IO SQL Server и видео демонстрации; они здесь не заменены вымышленными результатами.
