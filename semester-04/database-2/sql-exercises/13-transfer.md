# Перенос базы SQL Server

Работа выполняется только на учебном экземпляре. Убрать активные подключения к INAI_Contacts и убедиться, что сохранена резервная копия.

1. В SSMS открыть свойства базы → Files, записать фактические пути MDF и LDF.
2. Tasks → Back Up, сделать полную резервную копию и проверить Restore Verifyonly.
3. Tasks → Detach. После отсоединения скопировать оба файла на другой компьютер. Не удалять оригиналы.
4. На целевом сервере предоставить учётной записи службы SQL Server права чтения/записи файлов. Databases → Attach, указать MDF и путь LDF. Версия SQL Server должна быть совместима.
5. После присоединения проверить целостность и количество записей:

```sql
DBCC CHECKDB('INAI_Contacts') WITH NO_INFOMSGS;
USE INAI_Contacts;
SELECT COUNT(*) AS clients FROM klient;
SELECT COUNT(*) AS contacts FROM kontakty;
```

Для демонстрационного набора ожидается 12 клиентов и 72 контакта. Фактическую проверку переноса и снимки окна Attach следует получить на двух экземплярах SQL Server; здесь описан порядок действий.
