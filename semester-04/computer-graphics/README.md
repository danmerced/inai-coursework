# Компьютерная графика

Самостоятельный учебный пример: растеризация отрезка по Брезенхему, окружность, аффинные преобразования и заполнение многоугольника методом пересечений.

Открыть `index.html` в браузере, выбрать алгоритм и менять угол и размер. В `algorithms.js` находятся вычислительные функции. [Результаты запуска алгоритмов](results.md): проверены в Node.js; визуальный интерфейс требуется открыть в браузере.

Точный перечень лабораторных по дисциплине пока не найден.
