# Установка ОС, файловые системы и устройства

## Установка Ubuntu в виртуальной машине

- Создать VM типа Linux/Ubuntu 64-bit, 2 виртуальных CPU, 4 ГБ ОЗУ и динамический виртуальный диск 25 ГБ, если хост располагает ресурсами.
- Подключить официальный установочный ISO и загрузить виртуальную машину.
- Выбрать язык, раскладку, установку на виртуальный диск; убедиться, что выбран именно виртуальный диск.
- После загрузки отключить ISO, войти в систему, проверить `uname -a`, `lsblk`, `df -h`.
- Создать снимок VM до лабораторных работ.

Установка с флешки: создать загрузочный носитель из проверенного ISO, выбрать его в UEFI Boot Menu, убедиться в наличии резервной копии данных. Форматирование реального диска удаляет данные; для лабораторной использовать отдельный пустой виртуальный диск либо специально выделенный носитель.

## Сравнение

| Система | Особенность | Типичное использование |
|---|---|---|
| FAT32 | ограничение размера файла около 4 ГБ | совместимые носители |
| exFAT | большие файлы, широкая совместимость | флеш-накопители |
| NTFS | ACL и журналирование | Windows |
| ext4 | права UNIX и журналирование | Linux |

Проверять диски без исправления: Windows — `chkdsk` без /f, Linux — `lsblk -f`, `df -h`. Форматирование создаёт новую файловую систему; дефрагментация оптимизирует расположение данных HDD, для SSD обычно применяется TRIM. Архивирование уменьшает объём и объединяет файлы; проверка целостности — хеши или сравнение после распаковки.

## Ввод-вывод и архитектура

CPU выполняет инструкции, RAM хранит рабочие данные, контроллеры обслуживают устройства. Драйвер предоставляет ОС интерфейс к оборудованию. Прерывания сигнализируют о событиях ввода-вывода; DMA позволяет устройствам обмениваться данными с памятью без копирования каждого байта процессором.

В Windows изучить диспетчер устройств, свойства устройства и диспетчер задач; в Linux — `lscpu`, `lsblk`, `free -h`, `cat /proc/meminfo`. Не публиковать серийные номера и идентификаторы реального устройства.

Установка и действия в Windows требуют выполнения в VM.
